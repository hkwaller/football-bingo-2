# Famous 11s - Lineup Bank

This directory holds the curated Famous 11s lineup bank.

## Files

| File                  | Purpose                                                  |
| --------------------- | -------------------------------------------------------- |
| `types.ts`            | TypeScript types for lineups, slots, managers            |
| `lineups.ts`          | Original lineup bank + spreads extra/reverse waves       |
| `extraLineups.ts`     | Second-wave classics and Big Nights                      |
| `reverseLineups.ts`   | Opposite XIs for match fixtures                          |
| `enrichment.json`     | Generated by verify script - never edit by hand          |
| `index.ts`            | Merges enrichment, exports selection helpers             |

## Adding a Lineup

1. Find the Wikipedia match report (see Sources below).
2. Append a `Famous11sLineup` entry in `lineups.ts` with all 11 `slots`.
3. Set `x`/`y` pitch coordinates (0–100 %, y=0 = attacking top, y=100 = GK end).
4. Run `npm run famous11s:verify` to backfill `image`/`playerId` and check names.

## Coordinate Guide

```
y=0   ──── attacking end (strikers live here)
y=14  ──── CF / ST zone
y=33  ──── CAM zone
y=48  ──── midfield flat
y=57  ──── DM zone
y=72  ──── defender line
y=87  ──── GK
y=100 ──── GK end (touchline below pitch)
```

Common x values for n-wide lines:

- 1-wide: 50
- 2-wide: 37, 63
- 3-wide: 22, 50, 78
- 4-wide: 16, 40, 60, 84 (flat four)
- 5-wide: 12, 30, 50, 70, 88

- BBC/UEFA/FIFA match centre
